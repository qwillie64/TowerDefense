# 第一輪迭代

目前完成可玩 MVP：

```text
等待開始 -> 佔領 -> 建塔 -> 一波敵人 -> 防守或連攜 -> 勝利或失敗 -> 再次遊玩
```

## 執行方式

1. 使用 Unity 2022.3.62f3 開啟專案。
2. 開啟 `Assets/_Project/Scenes/VerticalSlice.unity`。
3. 進入 Play Mode。
4. 點擊 HUD 的「開始遊戲」。

HUD 使用 UI Toolkit。玩家、塔、敵人、據點、士兵與場景均使用 Unity 基本幾何建立。

## 操作

- `WASD`：移動。
- `Tab`：切換戰術俯視與第三人稱肩後視角。
- 第三人稱視角會鎖定滑鼠，移動滑鼠可旋轉鏡頭；切回俯視會解鎖滑鼠。
- `Esc`：暫停或繼續遊戲；暫停時會解鎖滑鼠。
- `T`：顯示或隱藏所有防禦塔的實際攻擊射程。
- `U`：花費資源升級附近的防禦塔，最高三級。
- `B`：開啟或關閉建造模式。
- `1` 至 `4`：選擇火、水、風、地元素塔。
- 滑鼠左鍵：在已佔領區域建塔。
- 滑鼠右鍵：取消建造模式。
- `R`：修理附近的塔。
- `Q`：在兩座相容元素塔的重疊射程施放連攜。

中立據點模組目前預設開啟。玩家站在中立據點附近完成佔領後，據點會定期產生幾何方塊士兵。

等待開始時可使用 HUD 按鈕開啟或關閉中立據點模組。若敵方先完成佔領，據點會轉紅並定期生產紅軍；紅軍會攻擊玩家、塔或主堡，也能被塔、藍軍與連攜技能消滅。

敵人目前在生成時暫時採用以下行為權重：15% 前往佔領仍為中立的據點、15% 前往攻擊現有防禦塔、70% 朝主堡進攻；若指定目標不存在，該敵人改為進攻主堡。敵人、防禦塔、中立據點、建造領地與主堡均以頭頂世界空間條顯示生命或佔領狀態。

敵人數值由 `Assets/_Project/Data/Enemies` 內的 `EnemyDefinition` 資產提供。關卡目前包含三波普通敵人與一波關卡王：基礎敵人生命 100、移速較慢；快速敵人生命 65、移速和攻擊頻率較高；關卡王生命 350，抵達主堡後會持續攻擊，不會直接退場，因此必須擊殺才能勝利。新增敵人時只需建立定義資產並在關卡 JSON 使用其 `enemyTypeId`。

擊殺基礎敵人、快速敵人與關卡王分別獲得 5、7、50 資源。塔現在會發射可見幾何投射物，命中與連攜會產生短暫脈衝效果。三種連攜除了範圍傷害外另有差異：火＋風造成燃燒、火＋地造成暈眩、水＋風造成緩速。

玩家、敵人、防禦塔、士兵與主堡的生命／耐久運算共用 `Vitality` 元件，新的戰鬥單位不需重複實作扣血、治療與死亡事件。

四元素塔的傷害、射程、攻速、投射物速度、耐久耗損、建造成本與升級曲線由 `Assets/_Project/Data/Towers` 內的 `TowerDefinition` 資產提供。塔升級後會提高傷害、射程與最大耐久。

敵人佔領與攻塔機率、佔領時間、近戰距離由 `EnemyBehaviorSettings` 資產提供。關卡載入時會交叉驗證 JSON 內的敵人 ID 與出生點 ID，錯誤資料不會靜默開始關卡。

關卡王每隔數秒會施放紅色範圍脈衝，傷害附近玩家與防禦塔。波次、擊殺、佔領、勝利與失敗均有執行時產生的基本提示音。

勝利或失敗後會自動回到俯視視角並解鎖滑鼠，可點擊「再次遊玩」重載目前關卡。

## 調整波次

編輯 `Assets/StreamingAssets/Levels/level_01.json`：

- `startTime`：進入波次流程後幾秒開始。
- `count`：敵人數量。
- `spawnInterval`：同一筆敵人設定之間的生成間隔。
- `enemyTypeId`：目前只支援 `enemy_basic`。

目前已配置四波，`startTime` 是相對於按下開始後的關卡時間，因此也同時定義波次之間的整備間隔。關卡王出現時 HUD 會顯示專用王血量。

地圖目前提供 `spawn_a`、`spawn_b` 兩個敵人入口。每筆敵人設定的 `spawnPointId` 會決定實際出生位置；第三波會同時從兩路生成敵人。
